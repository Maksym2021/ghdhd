    The first query you’ll write

    Same data you keep in a sheet. Five lines of SQL replace a filter, three SUMIFS formulas and a manual sort.

    In a spreadsheetsample data
    E2fx=SUMIFS(C:C, B:B, "North", A:A, ">=2026-10-01")
    ABC
    1order_dateregionrevenue

    One SUMIFS per region, then sort the totals by hand. Add a region and you edit the formulas again.

    In SQLruns in your browser
    revenue_by_region.sql 
    SELECT region, SUM(revenue) AS revenueFROM   ordersWHERE  order_date >= '2026-10-01'GROUP BY regionORDER BY revenue DESC;
