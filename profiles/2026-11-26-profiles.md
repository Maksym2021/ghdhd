## 1. Freelancer.com (английский)

**Шаги, около 10 минут:**
1. freelancer.com → Sign up → email и пароль (пароль придумайте сами, мне его не присылайте) → режим «I want to work».
2. Подтвердить email по письму.
3. Заполнить профиль текстами ниже, загрузить фото (лицо, нейтральный фон).
4. Подтвердить телефон. Подтверждение документов (KYC) понадобится для вывода денег, его можно пройти позже.
5. Добавить 2 демо в Portfolio.
6. Проверить, сколько откликов в месяц даёт бесплатный аккаунт, и тратить их только на верх списка из моих отчётов.

**Headline (заголовок):**
```
Landing pages + n8n automation that handles your leads
```

**Summary (описание):**
```
I build fast landing pages and the automation behind them, so every lead is captured and followed up without manual work.

What I do:
• Landing pages and small sites in clean HTML, CSS and JavaScript: mobile-first, fast, easy to edit
• Forms that go where you need them: Google Sheets, CRM, Mailchimp, email, Telegram
• n8n workflows: webhooks, Google Sheets, OAuth integrations, AI agents (OpenAI, Gemini)
• Instagram DM automation with ManyChat
• Telegram bots with AI answers
• API integrations between the tools you already use

How I work: I confirm the scope in writing, share progress every 1–2 days, and hand over everything (code, access, a short how-to) at the end.

Working demos:
• Single-product page with one-step checkout, confirmation email and order table: https://maksym2021.github.io/demos/stozek/
• Webinar landing page with validated sign-up form and lead flow: https://maksym2021.github.io/demos/rowcount/

Languages: English, Polish, Ukrainian, Russian. Based in Poland (CET).
```

**Skills (на Freelancer можно выбрать до 20 навыков, выбирайте из списка):**
Landing Pages, HTML, CSS, JavaScript, Website Design, Web Development, Frontend Development, n8n, Zapier, Make.com, Automation, Workflow Automation, AI Automation, Google Sheets, API Integration, Chatbot, Telegram API, Mailchimp, OpenAI, Instagram API

**Hourly rate:** 20 USD/ч на старте. После 3–5 отзывов поднять до 30–35 USD.

## 2. Freelancehunt (украинский)

**Шаги:**
1. freelancehunt.com → Реєстрація → «Фрилансер» → email.
2. Подтвердить email.
3. Заполнить профиль, выбрать навыки, загрузить фото.
4. **Включить email-уведомления о новых проектах** по вашим навыкам. По этим письмам я буду находить заказы в Gmail.
5. Добавить 2 демо в портфолио.
6. Проверить ограничения бесплатного аккаунта на отклики.

**Заголовок:**
```
Лендінги + автоматизація заявок (n8n, Google Sheets, Telegram)
```

**Про себе:**
```
Роблю швидкі лендінги та автоматизацію за ними, щоб кожна заявка автоматично потрапляла куди треба і клієнт отримував відповідь без ручної роботи.

Що роблю:
• Лендінги й невеликі сайти на HTML, CSS, JavaScript: адаптивні, швидкі, легко редагувати
• Форми із заявками в Google Sheets, CRM, Mailchimp, на пошту або в Telegram
• Автоматизації в n8n: вебхуки, Google Sheets, OAuth-інтеграції, AI-агенти (OpenAI, Gemini)
• Боти для Instagram на ManyChat
• Telegram-боти з AI-відповідями
• Інтеграції через API між сервісами, якими ви вже користуєтесь

Як працюю: фіксую обсяг робіт письмово, показую прогрес кожні 1–2 дні, наприкінці передаю код, доступи та коротку інструкцію.

Робочі демо:
• Сторінка товару з оплатою в один крок, листом-підтвердженням і таблицею замовлень: https://maksym2021.github.io/demos/stozek/
• Лендінг вебінару з формою реєстрації та обробкою лідів: https://maksym2021.github.io/demos/rowcount/

Мови: українська, польська, англійська, російська. Живу в Польщі.
```

**Навыки:** Лендінги, HTML та CSS верстка, Javascript, Веб-програмування, Створення сайту під ключ, Боти, Інтеграція API, Парсинг та автоматизація (выбирайте ближайшие из списка Freelancehunt).

**Ставка:** указывайте фиксированную цену за проект. Ориентир для лендинга с формой: 6 000–12 000 грн.

## 3. Уже есть: Upwork и Fiverr

- **Upwork** (аккаунт с 2023 года): откликаться без отзывов там дорого из-за платных Connects. Достаточно обновить профиль теми же текстами, что для Freelancer.
- **Fiverr** (аккаунт с 2023 года): там не нужно откликаться, клиенты приходят сами. Можно создать один gig, черновик ниже.

**Gig:** «I will build a landing page with lead automation to Google Sheets, CRM or Telegram»
| Пакет | Что входит | Цена |
|---|---|---|
| Basic | Лендинг на 1 экран + форма на email | 120 USD |
| Standard | Лендинг до 6 секций + форма → Google Sheets / Telegram | 250 USD |
| Premium | Standard + автоматизация n8n: письмо-подтверждение, напоминания, CRM | 450 USD |
